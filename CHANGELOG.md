# Changelog

All notable changes to the **Relations Suite** plugin will be documented in this file.

## [1.0.2] - 12-10-2026

### Fixed & Improved
- **Family Logic & Relationship Sync**:
  - Enhanced real-time synchronization across nuclear family members—adding a child or sibling now seamlessly links shared parents and siblings across notes.
  - Fixed relationship removal so deleting a relationship cleanly unlinks notes on both sides without re-adding them.
  - Improved consistency and reliability for custom relationship pairs across the vault.
- **Family Tree Viewer**:
  - Balanced branch spacing to eliminate awkward gaps and keep family units neatly arranged.
  - Improved connection lines, marriage links, and search dropdown responsiveness.
- **Relationship Path Graph**:
  - Fixed path tracing so finding connections between two people works consistently in both directions.
  - Refined graph layout to keep connected notes grouped in a clean, compact cluster.
  - Polished active path highlighting with smooth route cycling.
- **User Interface & Experience**:
  - Enhanced the overall visual feel and responsiveness across all views, delivering a smoother and more polished experience.

## [1.0.1] - 30-09-2026

### Changed
- Minor UI style adjustments, bug fixes, and Obsidian guidelines compliance updates.

## [1.0.0] - 30-09-2026

### Added
- Initial release featuring bi-directional relationship synchronization, interactive family tree visualizer, and relations graph path finder.
